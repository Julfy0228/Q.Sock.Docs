## Как устроена документация

Статьи находятся в `docs`, изображения — в `docs/assets`. Каждая статья имеет собственное имя; папки объединяют инструкции по назначению. Веб-сайт использует docsify 5.1.0, его файлы и лицензия включены в репозиторий. Главная страница сайта — `docs/overview.md`. Исходный код приложения находится в [Q.Sock](https://github.com/Julfy0228/Q.Sock).

## Обновление

Измените нужный Markdown-файл и проверьте ссылки и изображения. При добавлении статьи обновите `_sidebar.md` и `navigation.json`. Документация публикуется GitHub Pages из папки `docs` ветки `main`. Приложение получает исходные `.md` и изображения по HTTPS; пересборка приложения для изменения текста не требуется.

Тексты описывают доступные сценарии. Наличие отдельных функций определяется сервером, правами пользователя и расширениями.
