# Чаты и сообщения

Список чатов показывает личные и групповые диалоги. Пространства объединяют текстовые каналы и голосовые комнаты. Доступный набор чатов зависит от вашего участия и прав.

## Открытие и создание чата

Выберите чат в списке, чтобы увидеть историю переписки. В меню действий можно создать новый чат или пространство. Личный чат предназначен для двух пользователей; для общения нескольких человек создайте отдельный групповой чат.

На узком экране список и переписка открываются последовательно. Кнопка возврата над перепиской возвращает к списку. На широком экране обе области могут отображаться рядом.

## Отправка сообщения и файла

Введите текст в поле сообщения и нажмите кнопку отправки. На компьютере Enter отправляет сообщение, Shift+Enter добавляет новую строку. Для прикрепления файла нажмите кнопку с плюсом, выберите файл и отправьте сообщение. До отправки вложение можно убрать из списка.

*Размер вложения ограничивается настройками сервера.* Если отправка запрещена, проверьте сообщение о правах или обратитесь к администратору чата.

## Оформление текста

Markdown позволяет выделить *важное уточнение*, использовать **полужирное выделение**, заголовки и блоки кода. Например, `**текст**` выделяет текст полужирным, а `*текст*` — курсивом. Короткие коды смайликов сейчас остаются обычным текстом.

## История и права

Отметки прочтения показывают, что сообщение просмотрели участники. Для поиска нужной информации используйте доступный поиск по переписке. Возможность редактировать сообщения и управлять участниками определяется правами.

Для разговора голосом откройте [инструкцию по звонкам](calls.md). Если сообщение не отправляется, проверьте [возможные причины](../help/troubleshooting.md).
